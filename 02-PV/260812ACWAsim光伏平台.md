## 一、平台整体架构介绍

平台整体涵盖海水淡化、光伏 PV、光热 CSP、储能制氢、风电五大能源板块，各板块配套独立工具集，但开发与落地进度差异极大：

1. **光热 CSP**：配套工具仅电站运维人员少量使用，多年未迭代、无后续开发投入；

2. **风电 Wind**：平台内置功能极少，无研发投入、无专职风电研发人员，仅硬件设备安装，无配套算法与数据研究；

3. **储能制氢**：由 Hu Miao 负责相关板块工具；Christos团队负责电池相关模块；

4. **光伏 PV**：平台核心、投入最大、功能最完善，配套全套专业仿真 \+ 运维分析工具，也是本次讲解的全部重点，包含 PV Dashboard、PV Data Upload、PV System、PV Track、PV Bifacial、PV Soiling Map、PV Clean Logbook 七大工具。

## 二、光伏板块各工具功能

### （一）PV Soiling Map 光伏积尘损耗地图工具

1. **研发背景**：由 Ahmad Balavi 联合高校教授团队开发，在Kaust试点电站完成为期一整年、不同安装倾角下的积尘实地试验，基于实测数据搭建算法模型。

2. **核心两大功能**

    - 按月估算区域光伏积尘损耗：输入经纬度、选择电站 / 地理位置，自动输出该地点每月积尘造成的发电量损耗百分比，支持按项目 / 坐标两种筛选模式；

    - 新电站选址损耗外推预测：无需待建区域实地电站数据，依托实测算法模型，通过坐标推演未知区域积尘损失，为新建光伏项目前期评估提供数据支撑。

3. **数据逻辑**：仅Kaust试点使用真实实测数据，其余所有电站损耗数值均由算法推演生成，**不导入电站现场实测运行数据**，属于独立预测工具，无法对接现场实时数据。

4. **输入基础参数**：依托辐照、温度、电流等光伏电站通用可测基础参数，结合倾角算法完成损耗计算。

### （二）PV Bifacial 双面光伏仿真工具

1. **核心用途**：计算双面组件背面辐照、行间遮挡、失配损耗，是双面光伏系统设计仿真核心工具。

2. **使用输入条件**：录入项目几何参数（行距、组件规格等）\+ 对应地点 TMY 标准气象文件；

3. **输出仿真结果**：正面辐照、背面辐照、平均辐照、背面辐照失配损耗、矢量失配损耗，全部数据支持导出；同时生成遮挡热力图，直观展示阵列遮挡分布；

4. **核心优势

    - 商用 PVSIST 单次仅能单工况仿真，本工具支持**批量多工况运算**，可一次性搭建十组不同行距、组件方案自动批量计算失配因子，快速对比最优设计方案；

    - 底层算法依托商用 PVSIST 内核，平台封装远程访问接口，支持任意地点网页远程调用，无需本地安装 PVSIST 软件；

5. **开发分工**：我方团队提供底层物理逻辑、计算公式，外包第三方企业完成代码开发落地。

### （三）PV Data Upload 光伏数据上传模块

仅作为数据入口，要求电站运维人员按照固定格式上传光伏现场运行原始数据，上传的数据统一流入平台核心工具 PV Track，是运维分析的数据前置通道。

### （四）PV Track 平台核心综合运维分析工具（数据库体量最大、功能最全）

电站运维诊断核心载体，内置多套分析子功能，后端搭载机器学习模型（隐藏于后台，前端界面不直接展示模型操作），所有计算逻辑均内置标准化计算公式：

1. **数据归一化处理子功能**

分为组串归一化、逆变器归一化；选定电站、区块、组串、时间区间后执行归一化运算，对原始数据清洗校准，为后续损耗分析做预处理。
归一化后输出可视化图表：直流分层损耗、交流分层损耗、有功功率、面辐照、性能比；组串原始电流 / 电压 / 功率、归一化后电流 / 电压 / 功率，让运维人员直观掌握电站整体运行健康度、损耗来源与优化方向。

2. **清洁机器人运维监控子功能（Robot Performance）**

    - 可视化呈现电站阵列地图，每条线条代表一条光伏组串；颜色标记运行状态：红色 = 当日未完成清洁、积尘严重，绿色 = 清洁到位；

    - 支持时间轴播放，逐日查看组串清洁状态变化；可单点点击单组串，调取该组串长期积尘、清洁趋势曲线；

    - 判定逻辑：对接清洁机器人定位、位移运行数据，通过机器人坐标移动轨迹判断是否完成清扫；同时结合积尘损耗变化交叉验证，若损耗持续上涨且无清扫记录，判定机器人故障 / 卡滞；

    - 当前局限：仅支持离线上传历史数据分析，无电站实时在线数据流接入；若打通实时数据，可自动推送故障告警、提示运维人员重启 / 检修清扫设备。

3. **组串性能诊断子功能（String Performance）**
聚焦逆变器、光伏组串运行工况，同样采用阵列地图可视化，按时间维度查看各组串发电表现优劣，配套独立性能分析图表，定位低效故障组串。

4. **综合智能分析子功能（Analytics）**
多维度电站健康诊断体系：

    - 基础电气分析：功率、电流、电压正常 / 异常判定；

    - 组件衰减分析：基于发电功率时序数据测算组件逐年衰减程度；

    - 积尘趋势分析：积尘斜率曲线可视化，斜率正数 = 积尘持续加重、发电量损耗上升；斜率负数 = 清扫完成，损耗下降；曲线归零代表该时段无有效采集数据；可直观区分清扫周期与积尘累积周期；

    - 波动异常识别：逆变器无停机但发电量持续缓慢下降，自动判定为积尘加重，联动积尘校正电流指标，建立积尘与发电量的关联分析。

### （五）PV Clean Logbook 人工清洁台账工具

1. **适用场景**：无自动化清扫机器人的老旧光伏电站（如 Sakaka 项目），用于人工清扫记录管理；

2. **功能**：搭建清扫台账数据库，标记各组串清扫 / 未清扫状态；

3. **当前现状**：系统内仅创建空白模板，暂无任何电站实际清扫业务数据录入，暂无法落地使用。

### （六）PV Dashboard 光伏总览看板

平台配套可视化总览面板，但日常使用频次极低，无详细业务讲解。

## 三、平台现存短板与后续落地规划

1. **核心现存痛点**
全平台缺少各电站**实时在线数据流**，所有分析均依赖人工离线上传历史数据，无法实现实时监控、自动预警、动态诊断；风电板块完全停滞无研发，光热工具停止迭代。

2. **下一阶段工作目标**

    - 打通电站在线实时数据对接通道，由各电站持续推送现场运行数据至平台；

    - 面向一线电站运维人员开放整套仿真、运维分析系统，依托平台算法输出损耗诊断、运维优化建议，为电站创造实际运营价值；
